# Choosing a system

Compare each system at a stated acceptance target and referral capacity. Use a table with correct/accepted, accepted accuracy, coverage, errors, calls, measured model cost and separately referral cost. Plot accuracy against referral fraction, and full cost against quality. Do not rank a tiny high-confidence subset as if it answered the whole workload.

A lower-accuracy model with useful confidence may be an economical first stage. A stronger model can handle its uncertain remainder. Agreement can reject mistakes but correlated errors survive. A conditional ensemble spends additional calls on difficult items. The strict signal rule uses another model's confidence to decide whether to retain the primary answer; validate that signal on held-out data.

Our reserved ProofWriter thousand favored Microsoft → Jev for the measured cost/coverage balance. Strict selection produced higher accepted accuracy at substantially greater referral work. These are configurations to study, not fixed recommendations for unrelated tasks or current provider prices.
