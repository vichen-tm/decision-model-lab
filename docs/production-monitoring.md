# Production monitoring

Store task identity, prompt/model/policy version, outputs, confidence, calls, usage/cost and referral result. Audit random accepted decisions as well as rejected cases. Track distribution changes, class-specific error patterns, coverage, latency and total cost. Reevaluate on fresh labeled examples after meaningful changes, and preserve a rollback version. Protect inputs according to the user's data policy.

The full operating accuracy includes the real referral handler's performance. A model, human or rule engine receiving referrals must be evaluated on that difficult subset.
