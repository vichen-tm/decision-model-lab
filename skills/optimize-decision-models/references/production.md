# Production

Log input identity, versioned task/prompt/model/policy, outputs/confidence, routing decisions, usage/cost and referral outcome. Protect personal data and restrict retention to the user's needs. Keys are never part of a log.

Audit a random sample of accepted outputs as well as referrals; otherwise accepted errors remain invisible. Monitor class/input distribution, error types, coverage, price and latency. Use newly labeled data to revisit thresholds or models when the task/provider changes or quality drifts. Evaluate updates on fresh independent data and keep a rollback configuration.

Deliver a report containing the user's objective, data quality findings, baseline, prompt experiments, offline comparisons, chosen policy, final validation and cost accounting. Link the exact artifacts and document anything the user must operate manually. Choose the simplest system meeting the measured goal.
